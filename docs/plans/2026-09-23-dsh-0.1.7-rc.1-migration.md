## 行动（按文件）

- `src/client/tool-names.ts`：`ALL_TOOL_NAMES` 删 `cordis_package_inspect`/`cordis_runtime_inspect`；`TOOL_VARIANTS`/`TOOL_TITLES` 同步删除；注释说明新 `cordis_inspect_list`/`cordis_inspect_query`/`cordis_inspect_self` 走 ui-tool 自带 details 行、不接管。**RC1-14**。
- `src/client/card-model.ts`：`parsedArgsOf` 与 `callRowModel` 增加 `block.phase === 'preparing'` 分支（准备阶段无 `argsRaw` → `''`）；准备调用导出无参数、不可展开的 model。**RC1-23**。
- `src/client/rows.tsx`：
  - 图标换 `IconSearchOutlineRegular`/`IconBrowseOutlineRegular`/`IconApiOutlineRegular`/`IconEditOutlineRegular`/`IconCodeOutlineRegular`/`IconSparkleRegular`。**RC1-26**。
  - `MergedToolRowProps` 保持 `ToolCallViewProps & PropsLocale<'merge-tool-calls'> & { cfg }`；新增 `DispatchedMergedRowProps = StartedToolCallViewProps & …`。
  - 新增 `PreparingMergedRow`（`props.phase === 'preparing'` 时渲染无参数轻量行：variant 图标/标题 + `useToolCallArgumentsPartial()` 的原始参数前缀，`data-state="preparing"`，不可展开）；原 `MergedToolRow` 主体改名 `DispatchedMergedRow`；新增分派入口 `MergedToolRow(props) { if (props.phase === 'preparing') return <PreparingMergedRow …/>; return <DispatchedMergedRow …/> }`。**RC1-23**。
  - label 契约同步：`readLabels`/`diffLabels` 补 `codeLabel`/`wrapLabel`/`unwrapLabel`；`terminalLabels` 补 `noExitCode`；`diffLabels` 去 `files`。**API drift**。
- `src/client/locales.ts`：加 `codeBlock.title`/`codeBlock.wrap`/`codeBlock.unwrap`/`terminal.noExitCode`（照 `@deepseek-ai/dsh-client-locale` 公共词表）；删不再使用的 `diff.files`。
- `src/types.ts`：配置注释去掉已消失的 cordis 检查动词。
- `package.json`：peer + `@deepseek-ai/dsh-*` → `^0.1.7-rc.1`。**RC1-01**。（host 半已用 `@deepseek-ai/schemastery`，无需改；`dsh.client.inject` 不变。）
- `README.md`：默认覆盖工具清单、边界行为（准备阶段、cordis 只读检查）同步。
