## 行动（按文件）

- `package.json`：peers `^0.2.0-rc.1` → `^0.2.1-alpha.5`；cordis `^4.0.1` → `~4.0.5-alpha.2`。**J1-01**。
- `pnpm-workspace.yaml`：`minimumReleaseAgeExclude` 加 `@deepseek-ai/cosmokit@1.8.5` / `@deepseek-ai/schemastery@3.18.4`（配套 dev 解析）。
- `src/client/rows.tsx`：
  - `terminalLabels` 补 `commandLine: line => t('terminal.commandLine', { n: line })`（TerminalBlock 以 1-based 行号调用）。**J1-09**。
  - `PreparingMergedRow` 弃用已删除的 `useToolCallArgumentsPartial` prop，改为读 `block.args` 流式参数视图（`preparingSummary`）；原始 JSON 前缀不再对普通 toolview 暴露。**J1-08**。
- `src/client/card-model.ts`：新增导出 `preparingSummary(variant, args, cwd, home)`（镜像 ui-tool `argumentSummary`：file 变体读 complete 的 `file_path`，其余读流式 `description`）；导入 `ToolArgs`。
- `src/client/locales.ts`：zh/en 各加 `terminal.commandLine`（`命令第 {n} 行` / `Command line {n}`）。
- `src/client/dictionaries.ts`：19 份 override 词典各加 `terminal.commandLine`（保持每语言完整覆盖 `terminal.*` 的既有不变量）。
- `lib/`：随 build 重建入库（预构建策略）。

### 测试（fixture 契约漂移，运行时不可见但类型必改）

- `ToolCallHead`/`ToolResultNode` 新增必填 `name: string` 与 `args: ToolArgs`；`ChatNodeStore` 新增必填 `bottomSource(key)`（连同 `source`/`turnDataSource`/`processSource`）。
- `tests/rows.client.spec.tsx`：fixture 工厂补 `args`/`name`（`PartialArguments.fromText`）；store stub 补 4 成员；删 `useToolCallArgumentsPartial` 默认 prop；准备阶段用例重写为参数视图断言（closed `file_path` 摘要、bash 流式 `description`），新增 1 用例。
- `tests/card-model.spec.ts`、`tests/merge-run.spec.ts`：同型 fixture 修补。
- 工作区补 `node_modules/@deepseek-ai/dsh-util-values` junction（→ `dsh/packages/util/values`；node_modules 不入库）。

## 行为变化（用户可见）

- 准备阶段行的摘要不再显示原始 JSON 前缀（如 `{"file_path":"foo`），改为与官方行一致的参数视图读法：read/write/edit 显示已闭合的 `file_path`，bash/pwsh/run_code 等显示流式 `description`；两者都未到时仅显示 variant 标题。这是平台删除 preparing 原始前缀暴露后的必然结果。
